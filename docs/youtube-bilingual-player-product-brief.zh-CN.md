# YouTube 双语字幕学习工具｜产品与 UI 设计说明> 工作名称：EchoSub（暂定）> 产品形态：macOS 原生桌面应用> 技术方向：AppKit + YouTube 嵌入播放器> 文档用途：产品讨论、UI 设计与 MVP 开发对齐> 文档状态：第一版产品定义## 1. 产品概述EchoSub 是一个面向英语学习者的 macOS YouTube 双语字幕工具。用户粘贴一个 YouTube 视频链接后，可以直接在应用中观看视频、阅读按时间对齐的英文与中文字幕，并把字幕以悬浮窗或桌面歌词的方式显示在其他应用之上。用户可以点击任意一句字幕跳转到视频对应位置，也可以在观看过程中滚动浏览上下文。一句话描述：> 一个让 YouTube 英语视频拥有可点击、可悬浮、可长期保存的双语字幕体验的 Mac 小工具。播放器是产品入口，双语字幕才是核心能力。## 2. 用户问题现有 YouTube 字幕体验存在几个问题：- 自动翻译字幕通常只能覆盖在视频画面上，不方便同时阅读原文和译文。- 字幕以短促的机器切片显示，不适合按完整语义理解和跟读。- 用户无法方便地回看上下文，也很难点击某句话反复收听。- 当用户一边看视频、一边记笔记或使用其他应用时，字幕不能独立悬浮在桌面。- 感兴趣的视频分散在浏览器标签页、收藏夹和聊天记录中，没有形成专门的英语学习播放列表。## 3. 目标用户与使用场景### 3.1 目标用户- 能阅读基础英文，希望通过真实视频提高听力的人。- 经常观看英语访谈、播客、课程、技术分享和演讲的人。- 希望逐句回听、理解完整语义，而不只是快速浏览视频的人。- 会一边播放视频、一边使用 Obsidian、Notion、浏览器或代码编辑器记笔记的人。### 3.2 核心场景1. 用户在浏览器中发现一个英语视频，复制链接并粘贴到 EchoSub。2. 视频在应用内播放，右侧自动出现双语字幕。3. 字幕跟随播放自动滚动，高亮当前正在说的一句。4. 用户点击没听懂的一句，视频跳回对应时间重新播放。5. 用户打开悬浮字幕窗，把播放器放在一侧，边看边记笔记。6. 用户切换到桌面歌词模式，在使用其他软件时只保留当前双语句子。7. 关闭应用后，视频、观看进度、字幕与翻译结果仍然保留。## 4. 产品原则### 4.1 字幕优先播放器服务于字幕，不追求复刻完整 YouTube 网站。界面应尽可能减少推荐内容、评论和其他干扰。### 4.2 原文和译文必须稳定对齐英文原文、中文翻译和时间范围属于同一个字幕单元。不能因为翻译结果缺失或返回顺序变化而发生错位。### 4.3 观看不中断原字幕获取成功后立即显示。中文翻译可以逐批生成，不应阻塞视频播放和原字幕阅读。### 4.4 原生 Mac 体验窗口、快捷键、菜单、拖放、深浅色模式和多桌面行为应符合 macOS 使用习惯。整体感觉应轻巧、克制，而不是一个套壳网页。### 4.5 清楚表达能力边界无法嵌入、无字幕、网络失败或翻译失败时，应明确说明原因并给出下一步操作，不能只显示通用错误。## 5. MVP 范围### 5.1 第一版包含- 输入或粘贴 YouTube 视频链接。- 在应用内播放允许嵌入的公开视频。- 自动保存用户添加的视频，形成长期播放列表。- 获取视频已有的人工字幕或自动生成字幕，优先英语字幕。- 把碎片化字幕整理为适合阅读和跟读的完整短句。- 生成简体中文翻译并缓存。- 原文、中文、双语三种字幕查看模式。- 字幕随播放时间自动高亮和滚动。- 点击字幕跳转到对应视频位置。- 可缩放、可滚动、可置顶的悬浮字幕窗。- 一次显示当前一句的桌面歌词模式。- 保存播放进度、窗口位置、字幕和翻译缓存。- 视频无法嵌入时，提供“在 YouTube 打开”。### 5.2 第一版不包含- Google 或 YouTube 账号登录。- 私享视频、会员专属视频和付费视频播放。- YouTube 首页、搜索、评论和推荐流。- 导入用户的 YouTube 收藏列表或账号播放历史。- 没有字幕时自动下载音频并用 Whisper 转录。- 单词本、背词计划、AI 总结、问答和笔记系统。- 手机端和多设备同步。- 浏览器中播放视频时的自动时间同步。这些能力可以在核心字幕体验稳定后分阶段评估。## 6. 信息架构应用由一个主窗口、两个字幕窗口和一个设置窗口组成。```text主窗口├── 链接输入与全局操作区├── 播放列表├── YouTube 播放器└── 完整字幕面板独立字幕窗口├── 悬浮字幕窗：当前句 + 上下文，可滚动└── 桌面歌词：一次只显示当前双语句子设置窗口├── 字幕与语言├── 翻译服务├── 悬浮窗与桌面歌词外观└── 缓存与隐私```## 7. 主窗口### 7.1 总体布局默认采用三栏结构：```text┌─────────────────────────────────────────────────────────────┐│ 粘贴 YouTube 链接……                         添加 / 打开网页 │├──────────────┬──────────────────────────┬───────────────────┤│              │                          │ 字幕  原文/中/双语 ││   播放列表    │      视频播放器          ├───────────────────┤│              │                          │ 00:18  English... ││              ├──────────────────────────┤         中文……     ││              │ 视频标题 / 悬浮 / 歌词    │ 00:24  English... ││              │                          │         中文……     │└──────────────┴──────────────────────────┴───────────────────┘```- 左栏：播放列表，可折叠。- 中栏：播放器和当前视频操作。- 右栏：完整字幕，可折叠或调整宽度。- 窗口变窄时，优先保留播放器和字幕；播放列表折叠为侧边栏按钮。- 分栏宽度应支持拖动调整并记住用户上次选择。### 7.2 顶部链接输入区核心组件：- YouTube 链接输入框。- “添加并播放”主按钮。- 可选的粘贴图标按钮。- 当前视频无法嵌入时显示“在 YouTube 打开”。交互规则：- 用户粘贴合法链接后按 Return 即可添加并播放。- 支持 `youtube.com/watch`、`youtu.be`、`shorts` 和 `embed` 等常见链接。- 重复添加同一视频时不产生重复条目，直接定位已有条目并播放。- 链接不合法时在输入框下方显示简短错误，不使用打断式弹窗。- 应支持把链接直接拖入主窗口。### 7.3 播放列表每个视频条目建议显示：- 缩略图。- 视频标题。- 频道名称，可在获取到元数据时显示。- 视频时长。- 上次观看进度。- 字幕状态：可用、无字幕、待翻译、已完成或失败。列表交互：- 单击切换视频。- 当前播放条目有明确高亮。- 悬停时显示更多菜单：从列表移除、复制链接、在 YouTube 打开、重新获取字幕。- 支持拖动排序。- 删除属于可撤销操作，短时间内提供 Undo。- 第一版不需要文件夹、标签和复杂筛选。### 7.4 播放器区域- 使用官方 YouTube 嵌入播放器，只展示视频与其标准播放控制。- 保留 YouTube 必要的品牌、广告和播放器行为。- 应与字幕时间轴双向同步：播放驱动字幕，点击字幕驱动播放器跳转。- 播放器不可用时，用状态卡片替换黑屏。播放器下方的轻量操作区包含：- 当前视频标题。- 打开/关闭悬浮字幕窗。- 打开/关闭桌面歌词。- 在 YouTube 打开。- 可选：后退 5 秒、播放/暂停、前进 5 秒快捷操作。### 7.5 完整字幕面板面板顶部包含：- 标题“字幕”。- 模式切换：`原文`、`中文`、`双语`。- 自动跟随开关或状态按钮。- 更多菜单：重新翻译、复制全文、导出字幕。双语字幕行包含：- 时间戳。- 英文原文，视觉权重较高。- 简体中文翻译，视觉权重略低。- 当前播放句的高亮状态。- 悬停反馈，表达该行可点击跳转。交互规则：- 点击任意字幕行，跳转到该句开始时间。- 当前句进入视区中心附近，而不是始终贴在顶部。- 用户主动滚动后，自动跟随暂时暂停，并显示“回到当前字幕”。- 点击“回到当前字幕”后恢复自动跟随。- 用户选中文字时不触发视频跳转，便于复制英文或中文。- 翻译尚未完成时，原文立即可读，译文位置显示轻量加载状态。- 单句翻译失败时只影响该句，并提供单句重试，不让整个面板进入错误状态。## 8. 字幕单元与时间同步一个字幕单元包含：- 唯一且稳定的 ID。- 开始时间。- 结束时间或持续时长。- 英文原文。- 中文译文。- 原始字幕来源与翻译状态。字幕不是直接照搬 YouTube 的机器切片。系统会把过短的片段组合为一个完整、适合阅读的短句，同时避免单句过长。产品体验目标：- 一句通常对应约 2～8 秒语音。- 优先在句号、问号、感叹号等完整语义边界切分。- 长句可以在自然从句边界切分。- 高亮切换应稳定，避免在几个极短片段之间快速闪烁。- 视频拖动后，字幕应迅速定位到新的当前句。## 9. 悬浮字幕窗悬浮字幕窗是一个独立、可调整大小的面板，适合边看视频边阅读上下文。### 9.1 默认内容- 当前英文句与中文句。- 当前句上方和下方的若干字幕。- 当前句高亮。- 右侧或底部提供轻量滚动区域。### 9.2 窗口行为- 可自由拖动和缩放。- 支持 Pin：置于其他应用窗口之上。- 未 Pin 时作为普通窗口，遵循应用层级。- 记住最后位置、大小和 Pin 状态。- 可选择是否出现在所有桌面空间。- 窗口控件在鼠标移入时出现，移出后淡化，减少阅读干扰。### 9.3 顶部控制- Pin / 取消 Pin。- 原文、中文、双语切换。- 字号减小与增大。- 恢复自动跟随。- 切换到桌面歌词。- 关闭。### 9.4 字幕交互- 点击某句跳转到对应时间。- 可滚动查看上下文。- 用户主动滚动时暂停自动跟随。- 可选快捷动作：双击当前句重新播放。## 10. 桌面歌词模式桌面歌词是产品最有辨识度的模式。它是透明、无边框、始终可见的双语字幕层，一次只呈现当前一句。### 10.1 默认样式- 第一行英文，字号更大、权重更高。- 第二行中文，字号略小、颜色略弱。- 文本居中显示。- 使用阴影、描边或半透明底板保证在浅色和深色背景上都可读。- 不显示时间戳、滚动条和常驻控制按钮。### 10.2 两种交互状态**编辑状态**- 鼠标可选中窗口。- 可以拖动位置和调整宽度。- 悬停显示控制条。- 可以修改字号、背景透明度和对齐方式。**锁定状态**- 窗口穿透鼠标，不影响操作下面的应用。- 控制条完全隐藏。- 通过菜单栏图标或全局快捷键解除锁定。必须让“已锁定”状态容易理解，并提供明确的恢复入口，避免用户找不到窗口控制。### 10.3 可调项目- 字号。- 窗口宽度。- 文字对齐：左、中、右。- 英文和中文的上下顺序。- 半透明底板开关及透明度。- 仅英文、仅中文或双语。- 显示器选择，多显示器时记住所在屏幕。## 11. 全局快捷键建议第一版可提供以下默认快捷键，并允许用户修改：- 播放/暂停。- 后退 5 秒。- 前进 5 秒。- 重播当前句。- 上一句字幕。- 下一句字幕。- 显示/隐藏悬浮字幕。- 显示/隐藏桌面歌词。- 锁定/解锁桌面歌词。快捷键是学习体验的重要组成部分，但 UI 设计不需要把所有快捷键做成常驻按钮。## 12. 关键状态设计UI 需要覆盖以下状态，而不只是正常播放状态。### 12.1 首次打开 / 空状态- 清楚说明“粘贴一个 YouTube 链接开始”。- 输入框是页面第一视觉焦点。- 可展示 2～3 条能力说明：双语字幕、逐句跳转、桌面歌词。- 不需要复杂的新手教程。### 12.2 正在加载视频- 播放器区域显示骨架或进度状态。- 文案区分“正在读取视频”和“正在连接 YouTube”。### 12.3 正在获取字幕- 视频可以先播放。- 字幕面板显示独立加载状态，不遮挡播放器。### 12.4 正在翻译- 英文原文立即出现。- 可见区域优先翻译。- 每行译文独立显示等待状态。- 面板顶部显示轻量的总体翻译进度，不弹出阻塞式进度窗口。### 12.5 视频没有字幕状态卡片说明：> 这个视频没有可用字幕，暂时无法生成双语字幕。操作：重新检测、在 YouTube 打开、从播放列表移除。第一版不要暗示可以自动识别音频。### 12.6 视频禁止嵌入状态卡片说明：> 该视频不允许在第三方播放器中播放。主操作：在 YouTube 打开。次操作：保留到播放列表、从列表移除。如果字幕已经获取成功，可以允许用户继续阅读字幕，但应提示外部播放暂不支持自动时间同步。### 12.7 需要登录或年龄受限不在应用中提供账号和密码输入框。说明该视频需要在 YouTube 中验证身份，并调用默认浏览器打开。### 12.8 翻译服务未配置- 英文字幕仍正常工作。- 中文位置显示“设置翻译服务”。- 点击后直接进入设置窗口的翻译页。- 不要把缺少 API Key 表现成字幕获取失败。### 12.9 网络或翻译失败- 区分视频加载失败、字幕获取失败和翻译失败。- 支持局部重试。- 已缓存的字幕和翻译应继续可读。## 13. 设置窗口### 13.1 字幕与语言- 首选原字幕语言，默认英语。- 目标翻译语言，第一版固定或默认简体中文。- 默认字幕模式：原文、中文或双语。- 自动跟随默认开关。### 13.2 翻译服务第一版建议采用用户自带 API Key 的方式：- 翻译服务选择。- API Base URL，可为高级选项。- 模型名称。- API Key 输入和连接测试。- API Key 存入 macOS Keychain，不写入普通配置文件。### 13.3 悬浮字幕与桌面歌词- 字体与字号。- 文字颜色。- 背景和透明度。- 是否跨桌面显示。- 默认 Pin 状态。- 桌面歌词锁定快捷键。### 13.4 数据与缓存- 查看字幕和翻译缓存大小。- 清除字幕缓存。- 清除全部播放记录。- 恢复默认设置。## 14. 本地数据与持久化默认仅在本机保存：- 播放列表和排序。- 视频标题、缩略图等基础信息。- 上次观看时间和进度。- 原始字幕。- 中文翻译。- 悬浮窗和桌面歌词的位置、大小、样式与锁定状态。- 用户偏好设置。用户删除播放列表条目时，可以选择只移除条目，或同时删除该视频的字幕与翻译缓存。## 15. 隐私提示- 应用不要求用户登录 Google 或 YouTube。- 视频播放由 YouTube 嵌入播放器提供，YouTube 可能按照其政策处理播放数据。- 使用 AI 翻译时，视频标题和字幕文本会发送给用户配置的翻译服务。- API Key 只存储在 macOS Keychain。- 应用不上传播放列表、观看历史和窗口设置到开发者服务器。设置窗口中应有简洁、容易理解的隐私说明。## 16. 视觉方向建议关键词：原生、安静、专注、轻量、清晰。- 遵循 macOS 视觉语言，但不必完全照搬系统应用。- 同时支持浅色和深色模式，播放器场景可以默认偏暗。- 不要让大量边框分割页面，优先使用空间、层级和材质区分区域。- 英文原文是第一阅读层级，中文译文是第二层级。- 当前字幕高亮应明显但稳定，避免高饱和颜色不断闪烁。- 翻译加载、缓存成功等系统状态应轻量表达，不打断视频。- 悬浮字幕窗应比主窗口更具“歌词软件”气质；桌面歌词应尽可能隐形，只保留文字本身。## 17. UI 设计交付清单建议 UI 第一轮至少产出以下画面：1. 主窗口空状态。2. 主窗口正常播放 + 双语字幕状态。3. 播放列表展开与折叠状态。4. 字幕自动跟随状态。5. 用户滚动后暂停跟随的状态。6. 原文已显示、中文正在逐句翻译的状态。7. 视频无字幕状态。8. 视频禁止嵌入 / 需要在 YouTube 打开的状态。9. 悬浮字幕窗默认状态、Pin 状态和手动滚动状态。10. 桌面歌词编辑状态和锁定状态。11. 设置窗口的字幕、翻译、外观三个核心页面。12. 深色与浅色模式下的关键页面。## 18. MVP 成功标准第一版是否成立，可以用以下体验标准判断：- 新用户无需登录，在一分钟内能够粘贴链接并看到视频与英文字幕。- 有可用字幕的视频能够稳定生成时间对齐的双语内容。- 点击字幕后，视频能跳转到用户预期的位置。- 播放过程中，当前句高亮准确且不会频繁抖动。- 悬浮字幕和桌面歌词在切换其他应用后仍然清晰、稳定、可控。- 重新打开应用后，播放列表、进度、字幕和窗口位置仍然存在。- 局部翻译失败不会破坏已经生成的字幕。## 19. 后续版本候选能力以下内容不进入第一版 UI 主流程，但信息架构应避免完全堵死扩展空间：- 浏览器扩展，与 Safari 或 Chrome 中播放的视频同步。- 无字幕视频的本地 Whisper 转录。- 单句循环与 A-B 循环。- 选词查义、发音、收藏和生词本。- 字幕笔记和 Markdown 导出。- AI 解释当前句的语法、俚语和文化背景。- 导入 YouTube 播放列表。- 多种目标语言和多翻译服务。## 20. 已确定的关键产品决策- 第一版不做 Google / YouTube 登录。- 第一版不计划上 Mac App Store，采用独立安装包分发。- 播放优先使用官方 YouTube 嵌入播放器，不规避广告或播放限制。- 公开且允许嵌入的视频提供完整的应用内字幕同步体验。- 受限视频跳转到系统浏览器，不在应用内要求用户输入 Google 密码。- 字幕提取能力采用可替换的 Provider 设计，避免依赖单一第三方 API。- 翻译参考 YouTube Digest 的语义分句、稳定 ID、小批量翻译和缓存思路，但针对歌词显示缩短单句长度。- 第一版核心卖点是双语字幕窗口，而不是 YouTube 内容发现或 AI 总结。---这份文档描述的是第一版产品体验与 UI 边界。具体尺寸、颜色、字体和动效由 UI 设计阶段探索，但不应改变“字幕优先、无需登录、公开嵌入播放、两种独立字幕窗口”这四个核心约束。
